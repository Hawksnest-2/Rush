# Music1
repository to play randomized song list

To change the folder name from Music1 to ????
find this line in the index.html file

            audioPlayer.src = `Music1/${formattedNum}.mp3`;

change Music1 to the new folder name

to change the # of songs 
find this line in the index.html file

                nextSongNum = Math.floor(Math.random() * 20) + 1;

change the 20 to the new number of song files
